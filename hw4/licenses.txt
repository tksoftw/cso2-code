MIT: This license seems very permissive. From what I understand, as long as you include the copyright notice + license text that's all you need to use the software.
GPL: This license is much more restrictive. It seems like any project which distributes GPL code must also be under GPL.
BSD: Like MIT but you can't use the original author's name to endorse your project without permission.
BSD 3-Clause No Nuclear License: A modified BSD license that restricts use in certain domains. I chose this license because I think it is very cool.
